ASTRALSTUDIO

EconomySMP Core

INFORMATION:

AstralSMPCore is an all-in-one server core plugin for Paper/Purpur/Folia 1.21+ & support bedrock designed for Server Owners who are looking for a good and reliable SMPCore for their server. Built with performance and usability in mind, it merge all the systems you need & mechanics into a single lightweight package fully configurable.

FEATURES:

  • Fully optimized plugin
  • Active config support
  • Folia & Paper version
  • Bedrock Support

INCLUDED SYSTEMS:

  • Teleportation (spawn, homes, warps, RTP, TPA)
  • Economy with /pay, /balance, /shop, /baltop
  • Auction House with full trading system
  • Crates with rewards
  • Shards currency system
  • Bounty system with leaderboards
  • Duel & Trade systems
  • Admin tools & permissions
  • Custom scoreboard
  • Player settings menu
  • And about another 150+ features in total
