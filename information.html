Server Information

AstralStudio is a plugin development server that offers Minecraft plugins. Our plugins are 100% FREE and will forever be free.

Why choose AS Plugins

Our plugins are high-quality projects that are easy to use. We offer Economy plugins similar to the big DonutSMP experience, along with quick support that is available almost 24/7.

How to use Astral Plugins

Using AS Plugins is easier than you might think. Follow these steps and you can set up your server in seconds:

  1. Download the plugin you want to use from our BuiltByBit page.
  2. Upload the plugin .jar to your Minecraft server's Plugins folder.
  3. Restart your server. You should then see a new AstralXXX folder generated.
  4. Open the Astral folder and go to config.yml or license.yml. Paste the license key in the correct location. All Astral Plugins use one unique license key.
key: "THE-LICENSE-KEY-HERE"
  1. Finally, restart your server once again and the plugin should load.

If you have any problems or questions about one of our plugins, don't hesitate to ask us.
